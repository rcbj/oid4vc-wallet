# OID4VC Wallet

A Linux wallet for OpenID4VCI credential offers and OpenID4VP / SIOPv2 requests. It stores credentials, accepts credential offers, and answers same-device requests from iya-sts.

[How to use the wallet](guide.md) covers each page and each use case: receiving a credential, same-device presentation, a self-issued identity, import and export, and one window.

The program, the build, and the install are in the repository README.
