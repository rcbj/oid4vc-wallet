# OID4VC Wallet

The OID4VC Wallet keeps your credentials on this computer and uses them when a site such as iya-sts asks. It is a Linux program. The window title is OID4VC Wallet.

Open it from the application menu, or with:

```sh
oid4vc-wallet --ui
```

[How to use the wallet](guide.md) explains each screen.

## What do you want to do?

- [Open the wallet, or start it again after an update](guide.md#open)
- [Read a credential, including the kind of signature](guide.md#read)
- [Look at the issuer's certificates and copy one](guide.md#certificates)
- [Receive a credential, including several at once](guide.md#receive)

- [Create a sign-in identity](guide.md#identity)
- [Change the language, the registration, or the storage key](guide.md#settings)
- [Move credentials to another computer](guide.md#move)
